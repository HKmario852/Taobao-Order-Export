# Privacy policy

Order Exporter for Taobao (淘宝订单导出) does not collect, sell or send any data.

- It runs only on Taobao's 已买到的宝贝 page (`buyertrade.taobao.com/trade/itemlist/*`).
- It copies the order data that page loads for itself and keeps it in the page's memory until you close or
  reload the tab.
- When you click **Export**, it saves an Excel or JSON file to your computer through your browser's normal
  download. That file stays with you.
- It remembers your choices in the export dialog (fields, range, format) in that page's local storage.
  No order data is stored there.
- It makes no network requests of its own, has no analytics or tracking, and uses no remote code.
- It never exports addresses, phone numbers or recipient names.

Questions: open an issue at https://github.com/HKmario852/Taobao-Order-Export/issues.
